### C4. MercadoPago Webhook sin Verificacion de Firma

- **Archivo:** `src/app/api/webhooks/mercadopago/route.ts:4-14`
- **CWE:** CWE-345 (Insufficient Verification of Data Authenticity)
- **Codigo:**
```typescript
export async function POST(request: NextRequest) {
  const body = await request.json()
  if (!body.type || !body.data?.id) {
    return NextResponse.json({ error: 'Formato de webhook invalido' }, { status: 400 })
  }
  // No verifica header x-signature de MercadoPago
```
- **Descripcion:** No valida el header `x-signature` HMAC que MercadoPago envia. Un atacante puede enviar webhooks falsos para marcar ordenes como pagadas sin pago real, manipular estados de pedidos, o disparar workflows en n8n.

### C5. Payment Webhook con Autenticacion Trivialmente Bypasseable

- **Archivo:** `src/app/api/webhooks/payment/route.ts:8-13`
- **CWE:** CWE-287 (Improper Authentication)
- **Codigo:**
```typescript
const authHeader = request.headers.get('authorization')
if (!authHeader || !authHeader.includes('Bearer')) {
```
